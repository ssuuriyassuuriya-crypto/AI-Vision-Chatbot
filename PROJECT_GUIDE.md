# Project roadmap

## Architecture

Browser → Streamlit UI → Gemini API → Vision response → Chat UI

## Demo flow

1. Open the web app.
2. Upload an image.
3. Ask: `Describe this image in detail.`
4. Ask a follow-up: `What are the main objects?`
5. Ask another follow-up: `What colors stand out?`
